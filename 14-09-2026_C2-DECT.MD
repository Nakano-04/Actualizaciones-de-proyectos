Técnica Minimalista — Health Check Defensivo (no ofensiva)

> **Objetivo:** verificar salud del sistema sin tocar red, sin exploits, solo lectura local. Ideal para entender el proyecto en 30 segundos.

## Qué hace
- Lee **CPU, RAM, disco, uptime, procesos** vía WMI local (`Win32_Processor`, `Win32_OperatingSystem`, `Win32_LogicalDisk`).
- No abre puertos, no inyecta, no hace fuzz, no toca `LSASS`, no sale a internet.
- Resultado se muestra en `HealthMinimalView` con semáforo verde/amarillo/rojo.

## Por qué es minimalista
- **1 comando, 0 dependencias extra:** `wmic` / `Get-CimInstance` ya en Windows.
- **Lectura sola:** `SELECT * FROM Win32_Processor` — sin `Write`, sin `Execute`.
- **Fácil de entender:** 3 métricas, 3 colores, 0 falsos positivos.

## Técnica (defensiva, MITRE ATT&CK no ofensiva)
- **T1070 / T1497** (evasión de sandbox) pero en modo **defensivo**: detecta si el propio equipo es VM/sandbox para *no* ejecutar payloads (fail-closed).
- **T1005 / T1007** pero solo **inventario local**: lista procesos y servicios para hardenizar, no para exfiltrar.

## Cómo probarla
```powershell
# GUI: Exploit Lab → NORMAL → HealthMinimalView → REFRESCAR
# CLI:
wmic cpu get loadpercentage
wmic OS get FreePhysicalMemory,TotalVisibleMemorySize
wmic logicaldisk get size,freespace
```

public partial class HealthMinimalViewModel : ObservableObject
{
    [ObservableProperty] private string _cpu = "-";
    [ObservableProperty] private string _ram = "-";
    [ObservableProperty] private string _disk = "-";
    [ObservableProperty] private string _uptime = "-";
    [ObservableProperty] private string _status = "Pulsa REFRESCAR";
    [ObservableProperty] private string _statusColor = "#5a6070";
    [RelayCommand]
    private void Refresh()
    {
        try
        {
            // CPU
            using var s = new ManagementObjectSearcher("SELECT LoadPercentage FROM Win32_Processor");
            foreach (ManagementObject o in s.Get()) Cpu = o["LoadPercentage"]?.ToString() + "%";
            // RAM
            using var r = new ManagementObjectSearcher("SELECT FreePhysicalMemory,TotalVisibleMemorySize FROM Win32_OperatingSystem");
            foreach (ManagementObject o in r.Get())
            {
                long free = Convert.ToInt64(o["FreePhysicalMemory"]); long tot = Convert.ToInt64(o["TotalVisibleMemorySize"]);
                Ram = $"{(tot-free)/1024}MB / {tot/1024}MB";
            }
            // Disk
            using var d = new ManagementObjectSearcher("SELECT FreeSpace,Size FROM Win32_LogicalDisk WHERE DriveType=3");
            foreach (ManagementObject o in d.Get()) { Disk = $"{Convert.ToInt64(o["FreeSpace"])/1024/1024/1024}GB libre"; break; }
            Uptime = TimeSpan.FromMilliseconds(Environment.TickCount64).ToString(@"dd\.hh\:mm\:ss");
            Status = "OK — solo lectura local, no ofensivo";
            StatusColor = "#00e676";
        } catch (Exception ex) { Status = "Error: "+ex.Message; StatusColor="#ff5252"; }
    }
}
